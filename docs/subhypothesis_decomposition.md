# SH 分解的结构校验与纠错

自动 SH 分解使用 qwen/qwen3.8-max，生成 3–6 个可检索的研究问题。
提示词直接列出各个 question_kind 所需的 scientific_scope 轴和 required_slots，
并提供具有完整字段嵌套的结构示例。具体科学内容仍来自项目上下文。

## 无效响应的处理

首次响应通过 JSON 解析和检索契约校验后直接使用，正常路径只调用一次模型。
JSON 语法损坏、重复 JSON 键、必需范围为空或缺少槽位定义时，
系统将具体校验错误和最多 1600 字符的脱敏响应预览交给模型，
要求基于原始上下文重新生成完整对象。纠错请求保留预留的数据锚定 SH
和局部观测投影，并仅携带上一次失败的反馈，避免逐轮累积上下文。

最多生成三次（首次生成加两次纠错）。第三次仍无效时明确报错，
不会把损坏内容交给检索模块，也不会猜填丢失字段。
供应商超时或网络异常沿用调用层的处理，不作为结构错误重复生成。

## 日志与缓存

每次响应均记录脱敏、限长预览。校验失败日志包含 attempt、max_attempts、
retrying 和具体错误；成功产物包含 generation_attempts。
日志中的 …<truncated> 表示预览限长，不能据此认定供应商截断了完整响应。

只有通过校验的分解写入缓存；读取缓存时仍执行校验。
有效旧缓存继续复用，无效缓存会重新生成。
