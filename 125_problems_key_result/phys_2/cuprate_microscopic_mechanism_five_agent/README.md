# Five-Agent Study Package: Microscopic Mechanism of Cuprate High-Temperature Superconductivity

This directory is a direct, manual simulation of the repository's five-agent workflow:
`Survey -> Idea -> ExperimentDesign -> Quantitative -> Author`.

It was intentionally assembled without invoking `python -m src.cli` or altering
the incomplete parent science run. The main study remains a research proposal.
The Q1 branch contains one deterministic, assumption-driven numerical simulation
whose outputs are labelled `NUMERICAL_SIMULATION`, `SIMULATED`, and
`NOT_EMPIRICAL`; they are not measurements, a fit to data, or a proof of a
microscopic mechanism.

The final IEEE-style report is in `author/high_tc_cuprate_mechanism_report.pdf`.
The original editable diagrams are stored in `author/figures/*.drawio`.
