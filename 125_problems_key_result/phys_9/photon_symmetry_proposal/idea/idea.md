# Idea Agent Output: Symmetry-Operational Photon-State Ledger (SOPSL)

## Candidate search and selection

The Survey handoff forbids treating a photon with a reversed label as a new antiparticle. The Idea Agent generated four evidence-bound directions:

1. **Antiphoton discovery proposal.** Rejected: it violates the standard-model self-conjugacy invariant and would manufacture a particle distinction from a state label.
2. **A catalog of left/right photons.** Rejected as insufficient: it lists labels without defining which symmetry operation, reference frame, or measurement makes them opposite.
3. **Symmetry-Operational Photon-State Ledger (SOPSL).** Selected: it maps charge conjugation, parity/helicity, directional, polarization, and structured-mode transformations to invariant and distinguishable observables.
4. **Nonstandard composite-photon comparison.** Retained only as a boundary-screening note, not as a primary direction, because it is not accepted standard theory and cannot be treated as consensus evidence.

## Selected primary idea

**Title:** Symmetry-Operational Photon-State Ledger for Separating Self-Conjugacy from Measurable State Opposites

**Target gaps:** `GAP-SYMMETRY-001`, `GAP-OPERATIONAL-002`.

**Central hypothesis.** An operation-resolved ledger will classify a transformed one-photon density operator as identity-equivalent, measurement-distinguishable, convention-dependent, or out-of-scope. In particular, charge conjugation of the self-conjugate one-photon sector changes no density-matrix prediction, while helicity/direction and selected polarization/OAM transformations can change predictions for a fixed measurement context.

**Mechanism.** Represent a state by a declared mode basis, for example `|frequency, direction, helicity, OAM, transverse mode>`, and represent each alleged opposite by an operator plus an allowed observable set. Global phases cancel in `rho = |psi><psi|`; contrast labels must survive in measurement probabilities, a trace distance, or a process-tomography comparison before they may be called physically distinct.

**Falsifiers.** SOPSL fails if (a) charge conjugation of a self-conjugate photon produces a measurable density-matrix distinction under the declared model; (b) a purported helicity or OAM opposite has no operation/measurement declaration but is still classified; (c) a label changes solely because the reference convention changes; or (d) a result requires a nonstandard photon model but is reported as a standard-model conclusion.
