# Why Does Life Require Chirality?

This directory is a **simulated, evidence-bound four-agent research workflow**. It addresses whether chirality is functionally required by known biochemical systems and whether it is a universal requirement for every possible definition of life.

## Boundary of the result

- The output is a research proposal and literature-grounded analysis, not a laboratory result.
- `DESIGN_ONLY` applies to every phase: no molecular synthesis, cell culture, biological engineering, origin-of-life experiment, or new observation was conducted.
- Terrestrial biology is not described as using only one arbitrary ``right-handed'' chemistry. The relevant pattern is molecular **homochirality**: proteins predominantly use L-amino acids, whereas the sugars in DNA/RNA are D-configured.
- The report separates functional necessity in a specified chemical architecture from a claimed universal law about all possible life.

## Deliverables

- `survey/`: evidence plan, research-gap ledger, and structured handoff.
- `idea/`: constrained idea portfolio and selected research direction.
- `experiment_design/`: design-only evidence-synthesis and counterfactual-model protocol.
- `author/`: Markdown report, IEEE LaTeX source, compiled PDF, and PDF validation record.
- `figures/`: editable Draw.io representation of the four-agent workflow.
- `science_result.json`: unified deliverable index and limitations.
