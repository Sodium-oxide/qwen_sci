# Population Peak Persistence Atlas

This directory is an auditable, proposal-only four-agent research package for the question:

> Will the world's population keep growing indefinitely?

The scientific reframing is deliberately narrower than a yes-or-no prediction: **under what jointly specified fertility, mortality, migration, and climate-disruption trajectories would the global population continue increasing beyond 2100, and can a component-resolved ensemble distinguish those trajectories from trajectories that peak before 2100?**

The package follows the frozen sequence **Survey -> Idea -> ExperimentDesign -> Author**. It does not execute a demographic forecast, enroll people, collect records, or report observed findings. Every future-facing quantity is a planned observable or conditional outcome.

## Package map

- \`survey/\`: verified-source register, evidence plan, claims, and gap triage.
- \`idea/\`: evidence-bound portfolio and selected, falsifiable direction.
- \`experiment_design/\`: reproducible computational study design with no observed results.
- \`author/\`: IEEE-style English proposal source, compiled PDF, and rendering checks.

The local OpenAlex + AnySearch search adapter was attempted for four focused queries. Both providers returned connection-refused errors in this environment. The survey records this negative retrieval result explicitly; it relies only on separately browser-checked institutional and peer-reviewed anchors for claims.
