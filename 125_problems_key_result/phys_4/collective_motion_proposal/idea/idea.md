# Idea Agent Portfolio: Conditional Universals for Collective Motion

## Problem reframing

The central question is not whether a single microscopic rule explains every flock, school, swarm, or active suspension. It is whether a small set of **conditional, observable mechanism balances** predicts which collective state a system enters and how well that state transmits information. This framing targets Survey gaps G1--G4 and rejects the unsupported universal-coefficient claim G5.

## Candidate portfolio

| I5 | Correlation-only universality classifier | Works with sparse trajectories | Conflates correlation with causal interaction | Rejected: violates G2 |

## Selected idea: MOSAIC

MOSAIC constructs a cross-domain state atlas in which a group is not represented only by its species or by a visual flocking label. Each observation window is described by: (1) self-propulsion persistence; (2) inferred neighbor-coupling gain and interaction-network uncertainty; (3) directional or velocity noise; (4) response delay; (5) environmental geometry or confinement; and (6) a measurement vector containing polarization, connected correlation, correlation length, information-propagation lag, density heterogeneity, and vortex/defect statistics where meaningful.

The key hypothesis is conditional: after observation and context are standardized, a shared latent state model will predict held-out collective observables and short-horizon trajectories at least as well as a domain-specific baseline within a pre-registered practical margin. The model may use domain-specific observation maps and coefficients. It does **not** require a bird, fish, bacterium, and robot to implement the same local decision rule.

## MCTS-style evolution record

1. **Root:** Search for one law of collective motion. Score: novel but scientifically overstrong.
2. **Mechanism split:** Separate dry alignment, hydrodynamic coupling, sensing, and geometry. Score: more faithful but not yet testable.
3. **Observable split:** Separate polar order, correlation, propagation, and prediction. Score: aligns with G2 and yields measurable endpoints.
4. **Falsification edit:** Require held-out cross-domain and perturbation-context comparisons to a domain-specific model. Score: raises scientific maturity.
5. **Portfolio synthesis:** MOSAIC retains shared state semantics, allows domain-specific measurements, and has an explicit failure outcome: no supported conditional invariant.

## Falsifiable claims

- C1: A joint state vector predicts collective regime and short-horizon trajectory distributions better than a model using polarization alone.
- C2: A shared latent-state model remains non-inferior to domain-specific baselines on at least one held-out domain only when delay and geometry moderators are included.
- C3: If the shared model fails its pre-registered prediction margin or requires incompatible state semantics across domains, the claimed cross-scale principle is rejected rather than rescued by post-hoc redefinition.
