# Idea Agent Output: DimensionBridge Portfolio

## Intake and invariants

The Idea Agent received the Survey handoff with gaps `G1`--`G6`. It preserves the distinction between observed four-dimensional effective physics and higher-dimensional theory space. The agent rejects directions that promise to count dimensions from a single instrument, treat a string-theory consistency condition as empirical confirmation, or turn a null result into a global no-go theorem.

## Selected primary direction

**D3 -- DimensionBridge: A Cross-Scale Falsifiability Atlas for Extra-Dimension Models.**

DimensionBridge treats a model as a chain:

`model class -> parameter domain -> low-energy mapping -> channel-specific observable -> likelihood/limit -> model status`.

The method does not average incompatible constraints into one “dimension count.” Instead, it identifies where channels genuinely probe the same parameter region, where their conclusions depend on distinct assumptions, and where an anomaly has a plausible non-extra-dimensional explanation. The resulting status taxonomy is:

- `EXCLUDED_WITHIN_ASSUMPTIONS`
- `CURRENTLY_COMPATIBLE`
- `SENSITIVITY_LIMITED`
- `OBSERVATIONALLY_UNIDENTIFIABLE`

## Primary falsification conditions

- The framework labels a model excluded while a declared parameter/assumption remains unconstrained by all included channels.
- The framework treats a generic modification of gravity as uniquely evidence for extra dimensions without a competing-model comparison.
- Joint analysis changes a model status only because incompatible likelihoods or priors were silently combined.
- The non-identifiability audit never returns `OBSERVATIONALLY_UNIDENTIFIABLE` for models with no accessible observable map.
- Independent reviewers cannot reproduce the model status from the registry, assumptions, and decision ledger.

## Handoff to ExperimentDesign

Design a computational, literature-bound synthesis and forecast study. Use public likelihood summaries or published constraint contours where legally and technically available; otherwise record the model as sensitivity-limited rather than inventing data. Do not claim to run a collider analysis, torsion-balance experiment, gravitational-wave reanalysis, or cosmological inference. The required outputs are model statuses and reason codes, not an empirical discovery.
