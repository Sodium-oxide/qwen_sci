# Idea Agent: Digital Engram Fidelity Ladder and Causal Transfer Atlas

## Intake and reframed problem

The Survey handoff establishes that "digital memory" can mean a classifier, a stimulation policy, a behavioral association, a reinstated neural state, or a first-person recollection. The Idea Agent must therefore choose a direction that makes these meanings measurable without treating a lower-level success as a higher-level one. The selected project is designed to answer a sharper question:

> What is the highest fidelity at which a memory can be digitally represented and manipulated, and what evidence would be required before calling a transferred representation the same memory rather than a similar behavior?

## Candidate routes

**R1: Memory phenotype ontology and fidelity ladder.** Define content, temporal order, relational structure, affective response, behavioral expression, neural reinstatement, and subjective report as separable endpoints. Build an evaluation matrix from decoding to transfer. This directly addresses G1 and G5, but it needs a concrete neural and causal test.

**R2: Distributed engram state-space emulator.** Model memory as a time-dependent state across hippocampal, cortical, and associated circuits rather than a static cell set. Fit encoding, consolidation, retrieval, and reconsolidation states using latent dynamical models. This addresses G2 and G4, but an emulator can generate plausible activity without preserving memory content.

**R3: Cross-subject content alignment.** Learn an invariant representation of task-defined memory features across sessions and, where ethically and scientifically justified, across subjects. Test whether relational and temporal structure survives alignment rather than merely transferring a response policy. This addresses G3 and G7, but anatomical and experiential differences make identity claims difficult.

**R4: Closed-loop memory prosthesis.** Use subject-specific neural activity to construct stimulation or decoding policies for constrained recall tasks. Evaluate memory performance, neural reinstatement, false details, and collateral memories. This addresses G3 and G6, but improved task accuracy is not equivalent to portable memory storage.

**R5: DEFL-CTA.** Combine R1-R4 into a gated atlas. Each memory representation is assigned a fidelity level only after passing independent content, neural, behavioral, generalization, and causal tests. This route covers G1-G6 and turns the phrase "transplant memory" into a sequence of falsifiable claims.

## Selected primary direction

**Digital Engram Fidelity Ladder and Causal Transfer Atlas (DEFL-CTA).** The core hypothesis is:

> If a digital representation preserves a target memory at fidelity level $k$, then it should reproduce the level-$k$ content and relational structure under held-out cues and contexts, remain distinguishable from non-target and nuisance states, and show selective causal sensitivity when the corresponding representation is manipulated.

For a target memory $m$, define a fidelity vector
\begin{equation}
\mathbf F(m)=\left(F_{\mathrm{content}},F_{\mathrm{temporal}},F_{\mathrm{relational}},F_{\mathrm{neural}},F_{\mathrm{behavioral}},F_{\mathrm{subjective}}\right).
\end{equation}
The vector is not a universal score. It records evidence at distinct levels. A memory can be behaviorally expressed but fail content or relational tests; it can show neural reinstatement without evidence of subjective recollection.

The principal novelty is the **promotion gate**. A representation cannot be called stored merely because it can be decoded, and it cannot be called transplanted merely because another subject displays a similar behavior. Promotion requires content-specific generalization, collateral-memory controls, and, for the strongest claim, a selective causal effect on the target representation. Subjective recollection is retained as a separate level because a report alone is not an independent neural validation, but it cannot be silently replaced by an animal behavior proxy.

## Falsification and alternative explanations

DEFL-CTA is falsified as a useful framework if a low-level classifier or generic stimulation policy passes all proposed tests without preserving target content, or if the fidelity levels cannot be separated empirically from arousal, motor preparation, expectation, or task strategy. A representation fails the content claim if it predicts old versus new trials but cannot reconstruct held-out relational features. It fails the transfer claim if performance drops to a non-target baseline after cross-subject alignment. It fails the causal claim if target and non-target perturbations have indistinguishable effects or if the intervention changes general excitability and affect.

Alternative explanations are explicit: natural forgetting, rehearsal, semantic learning, experimenter cueing, state-dependent recall, decoder leakage, subject-specific motor strategy, and post-retrieval reconsolidation. These explanations become design controls rather than after-the-fact caveats.

## Portfolio decision

DEFL-CTA is primary. R1 is the methodological foundation, R2 provides the dynamic biological model, R3 is the high-risk cross-subject branch, and R4 is the translational branch. A pure “memory upload” route is rejected because it assumes the conclusion in its name. A pure rodent engram activation route is rejected as a complete answer because it lacks human episodic content and digital transfer. A decoder-only route is rejected because predictive access is weaker than storage and causal use.

## Expected contributions

1. A fidelity ladder that separates classifier, policy, association, neural reinstatement, and recollection claims.
2. A state-space representation for distributed and time-dependent memory traces.
3. A cross-context test of content, temporal order, relational structure, and false-detail generation.
4. A causal promotion rule with target, non-target, sham, and collateral-memory controls.
5. A transparent vocabulary for reporting what was stored, manipulated, transferred, and what remains unknown.

## Status

This is an Idea Agent output. No memory has been uploaded, edited, implanted, decoded from a participant, or transplanted. All experimental statements in the downstream design are conditional proposals.
