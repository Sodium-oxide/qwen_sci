## Portfolio

### Selected primary idea: FateLedger

**FateLedger: A Multi-Scale Cosmic-Fate Falsifiability Atlas** is a computational theory framework. It takes a declared cosmological model family, its permitted asymptotic continuation, and a frozen set of observational likelihood inputs. It returns four objects:

1. a background-expansion status;
2. an event definition and a time integral only if the model makes the integral well-defined;
3. a separate vacuum-stability status; and
4. a discriminator plan, or the explicit label FUTURE_BEHAVIOR_OBSERVATIONALLY_UNIDENTIFIABLE.

The central intervention is not an additional phenomenological fit. It is a mandatory **asymptotic-assumption card**. A model can be fit over the observed interval only after the card states whether the parameterization is a local interpolation, a physically defined field theory, a constant equation of state, or a model with a specified future potential. The atlas then prohibits a fate conclusion that is unsupported by the card.

The claim is falsifiable. If model families with genuinely distinct fate classes generate observationally separable predictions across the available data channels, then the unidentifiability label should shrink; if a proposed discriminator has no expected separation after systematic uncertainties are propagated, it cannot be credited as a fate measurement.

### Competitive idea: Redshift-to-Recollapse Forecast Ladder

This direction would forecast how BAO, supernovae, redshift drift, and standard sirens bound scalar-field potentials that can change sign. It is valuable for the specific Big-Crunch route, but it leaves phantom singularities and vacuum decay outside its core output. It was not selected because G2 requires an all-fate separation architecture before a specialized forecast.

### Competitive idea: Bayesian Future-Continuation Ensemble

This direction would place priors over physically motivated future continuations and report posterior fate weights. It creates a useful statistical object but is vulnerable to prior-dominated apparent certainty. It is retained as a method component of FateLedger rather than selected as a standalone primary direction.

### High-risk idea: Laboratory-analog vacuum-decay calibration bridge

Quantum-simulator or superfluid analogs could test aspects of bubble-nucleation dynamics. The idea is high-risk because analog validation does not directly calibrate the Standard Model vacuum lifetime. It is retained as a conceptual future connection but excluded from the primary proposal's core claims.

## Constrained scientific debate

**Pro position.** The ledger creates a scientific gain because it turns an often rhetorical fate question into testable contracts: assumptions, predictions, observables, thresholds, and failure modes. It aligns to G1-G4 and preserves the distinct physics of G5.

**Challenge.** The framework could become a bookkeeping exercise whose labels depend on arbitrary priors or parameterizations. A misleading classifier would merely formalize uncertainty.

**Resolution.** FateLedger is accepted only with pre-registered continuation classes, sensitivity analysis over priors and parametrizations, posterior-predictive checks, and a mandatory unidentifiable output. Its primary evaluation is not whether it produces an attractive date; it is whether it prevents unsupported dates while identifying data combinations that can genuinely separate model families.

## Selected hypotheses

* **H1:** Explicit asymptotic-assumption cards prevent finite-redshift equation-of-state fits from being reported as unsupported infinite-future claims.
* **H2:** A combined multi-probe predictive check distinguishes some expansion-fate classes more robustly than a single-probe parameter fit.
* **H3:** Separate expansion and vacuum-decay ledgers reduce logical contradictions and source misuse relative to a single "end-of-universe" output.
* **H4:** When alternative future continuations yield indistinguishable accessible observables, the correct research output is an observational non-identifiability status rather than a numerical forecast.

FateLedger is therefore a research proposal for making cosmic-fate claims narrower, more decisive where evidence permits, and explicitly unresolved where it does not.
