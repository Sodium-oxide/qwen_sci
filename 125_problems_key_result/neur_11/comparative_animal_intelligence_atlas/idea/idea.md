# Idea Agent Result

## Primary direction: Ecological Cognitive Architecture Atlas (ECAA)

ECAA argues that nonhuman intelligence is a cognitive mosaic rather than a single ladder. A partially shared architecture for flexible learning, inhibition, transfer, and problem solving may be detectable across species, but it will coexist with strong domain-specific expertise. Crows may be unusually effective at material transformation because their ecology and beak-hand system make such behavior useful. Dolphins may excel at acoustic-social processing in an underwater communication niche. Octopuses may solve object and camouflage problems through a distributed nervous system and highly exploratory arms. Chimpanzees may show exceptional performance in some memory or social-learning paradigms without matching humans in every abstract task.

The main idea is not to average these capacities into one intelligence score. It is to estimate a latent flexibility factor, estimate species-specific domain factors, and test whether ecological affordances and social learning explain the residual structure. The model makes a concrete prediction: after measurement reliability is controlled, a shared factor should account for some cross-domain covariance, but a mosaic model should predict held-out tasks better than a universal-factor leaderboard.

## Candidate routes

### Route A: Universal leaderboard

This route ranks species using a common set of tasks. It is rejected as the primary direction because a common task can be fair only if the sensory and motor requirements are shared. A visual touchscreen can favor primates; a fine hook-making task can favor corvid morphology. The route remains a negative control.

### Route B: Domain-specific expertise

This route treats intelligence as a collection of modules: tool manufacture, acoustic modeling, spatial memory, social recognition, inhibition, and object manipulation. It is empirically realistic but risks explaining away all common structure. ECAA retains these modules but tests whether their covariance contains a shared flexibility component.

### Route C: Social intelligence

This route predicts cognition from group living, bonding, cooperation, and social learning. It is retained as a moderator and learning condition, not as a universal cause. Rooks, chimpanzees, dolphins, and some birds provide informative contrasts.

### Route D: Ecological affordance model

This route predicts that body plan, sensory world, diet, tool ecology, and developmental experience shape problem solving. It is essential for octopus and dolphin comparisons and prevents a human-centric test from defining intelligence.

### Route E: Neural architecture model

This route connects behavior to brain organization, including pallial/cortical association systems, fronto-striatal learning circuits, hippocampal memory systems, cerebellar timing, and cephalopod distributed control. It is used cautiously because neuroanatomical homology across distant lineages is not one-to-one.

## Portfolio decision

ECAA combines Routes B, C, D, and E, with Route A as a negative control. It is selected because it can explain both extraordinary specialization and cross-task transfer. The high-risk extension is a phylogenetic Bayesian model that estimates independent evolutionary origins of flexibility and domain expertise. The competitive alternative is a domain-only model with no general factor. ECAA wins only if the shared factor adds reproducible held-out prediction without erasing species-specific structure.

## Falsification logic

ECAA is weakened if the shared factor disappears after task reliability and motivation controls, if affordance variables fail to explain species-by-task residuals, if social-learning conditions do not change later problem solving, or if a single-factor leaderboard predicts every held-out domain as well as the mosaic model. These are useful failures: they identify whether cross-species similarity is real, ecological, or an artifact of task design.

## Downstream handoff

ExperimentDesign must use a two-layer battery: computational-core tasks that can be expressed in species-appropriate forms, and ecological modules that preserve each species' natural affordances. It must model learning curves rather than only final accuracy, include individual and observational-learning conditions, and avoid claiming human-like language, theory of mind, or abstract representation from one trained response. No empirical outcomes may be inserted before data collection.
