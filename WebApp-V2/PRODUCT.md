# QwenSci

## Platform

Web, React, TypeScript, Vite. Same-origin FastAPI deployment in a controlled single-workspace environment.

## Users and Purpose

Researchers progress from a question and registered materials through literature review, ideas, experimental design, quantitative review and author handoff. Standalone tools support data plots, scientific schematics, academic polishing and PDF translation.

## Product Truth

Server snapshots own state and allowed actions. Durable events permit reconnection. Human review, source maps, immutable execution identities and versioned artifacts keep scientific claims tied to evidence. Attempts and content revisions are distinct. Public previews are explicitly static or representative.

## Constraints

The first release has no multiuser accounts or ACL, R execution, reference-image editing, image-page translation or original PDF layout reconstruction. Preferences apply to future jobs. Remote processing respects material scope, network consent and local-only preferences. No private document content is persisted by the browser.

## Approved Direction

The user requested implementation of the attached frontend plan: research-report marketing, interactive representative preview, six real workspaces, dark surfaces, warm text, serif display, indigo navigation and amber primary actions. Preserve the existing quantitative approval chain.
