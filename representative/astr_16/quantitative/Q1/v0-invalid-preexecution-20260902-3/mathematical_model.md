Abstract— A parsimonious ordinary differential equation framework simulates the coupled spin-period and magnetic-inclination evolution of neutron stars. The model integrates vacuum dipole braking, optional wind enhancement, smooth inclination decay, and a finite-duration accretion spin-up phase. Population-level outputs are generated by repeated deterministic integration across sampled initial conditions, enabling statistical comparison of braking-index and period-derivative distributions against observational surveys.

# Assumptions
- **A1**: Vacuum dipole radiation provides the dominant torque for isolated spin-down, modulated by inclination angle. Violation biases spin-down rates and braking indices.
- **A2**: Magnetic inclination angle decays exponentially toward alignment on a fixed timescale tau_alpha. Violation misrepresents torque geometry evolution.
- **A3**: Accretion-driven spin-up applies a constant-magnitude torque proportional to Mdot during a finite interval t_acc. Violation prevents reproduction of recycled pulsar characteristics.
- **A4**: Glitches, magnetospheric mode changes, and internal structural variations are negligible over the simulated horizon. Violation removes stochastic timing noise.

# Symbols

- **S_tau_alpha**: Inclination decay timescale tau_alpha, unit: s, dimension: time, role: PARAMETER
- **S_Mdot**: Mass accretion rate dot{M}, unit: kg_s^-1, dimension: mass_time_inverse, role: PARAMETER
- **S_K_acc**: Effective accretion spin-up constant K_acc, unit: s^2_kg^-1, dimension: time_squared_mass_inverse, role: PARAMETER

- **S_N_mc**: Monte Carlo sample count N_mc, unit: dimensionless, dimension: count, role: PARAMETER

# Equations
- **Q1-EQ-001** (DYNAMICS): dP/dt = -K_dipole * B_0^2 * sin^2(alpha) / P^3 + (t < t_acc ? -K_acc * dot{M} : 0). Where symbols: S_P, S_alpha, S_K_dipole, S_B0, S_K_acc, S_Mdot, S_t_acc.
- **Q1-EQ-002** (DYNAMICS): dalpha/dt = -alpha / tau_alpha. Where symbols: S_alpha, S_tau_alpha.

# Algorithm
**Input**: Scenario definitions, Parameter set, Initial condition priors
**Output**: Integrated state trajectories, Derived diagnostic arrays, Population histograms
**Steps**:
1. Initialize parameter dictionary with approved scalar values.
2. Iterate N_mc times to generate independent pulsar tracks.
3. For each iteration, select scenario-specific parameter overrides.
4. Integrate the ODE system from t=0 to t=T_max using adaptive stepping.
5. Compute derived observables (Pdot, n, tau_c) from state trajectories.
6. Discard tracks violating boundary conditions or falling below detection thresholds.
7. Aggregate surviving tracks into scenario-specific distribution summaries.

# Parameter and Scenario Material
**Parameters**: P0=0.5 s, alpha0=0.7854 rad, B0=1.0e8 T, K_dipole=9.765625e-32 s_T^-2, eta=0.1, tau_alpha=3.15576e14 s, Mdot=6.3e14 kg_s^-1, K_acc=6.3e-31 s^2_kg^-1, t_acc=3.15576e14 s, T_max=3.15576e15 s, Pdot_min=1e-22, N_mc=5000.
**Scenarios**:
- `isolated_dipole`: Overrides K_acc=0.0, Mdot=0.0, t_acc=0.0. Represents pure vacuum dipole evolution.
- `binary_recycling`: Overrides K_acc=1.5e-29. Activates accretion spin-up torque during the defined accretion window.

# Numerical Validation Plan
- **VP1**: Analytical benchmark against pure vacuum dipole solution P(t) ~ sqrt(P0^-2 + 2*K*t).
- **VP2**: Cross-scenario consistency check ensuring accretion switch produces distinct P-minima.
- **VP3**: Statistical comparison with ATNF Pulsar Catalogue P-Pdot projections using Kolmogorov-Smirnov tests.

# Limitations
- Excludes glitch events, magnetospheric state transitions, and variable moment-of-inertia effects.
- Accretion torque is modeled as a constant proxy rather than resolving disk physics or magnetospheric radius dependence.
- Observational selection biases and survey sensitivity functions are not embedded in the forward model.
